# 🪙 Coin Flip App

A fun and simple JavaScript app that flips a virtual coin and shows you whether it's Heads or Tails. Built as a quick project to practice random number generation, event handling, and DOM updates — with a little visual flair.

---

## 🎮 How It Works

- Click the **Flip Coin** button
- The app uses `Math.random()` to decide heads or tails
- The result is displayed immediately on screen
- (Optional) Keeps track of how many times each result appears

---

## 💻 Tech Stack

- HTML  
- CSS  
- JavaScript (Vanilla)
